## Sobre o projeto

O **Orbit** está sendo desenvolvido para explorar a construção de uma aplicação de comunicação: da interface de acesso à organização de conversas em canais e à troca de mensagens em tempo real.

O projeto acompanha um tutorial como referência e evolui com adaptações feitas durante o aprendizado. A proposta é entender cada parte da aplicação, personalizar os componentes e conectar, progressivamente, interface, autenticação e dados.

## 🛠️ Tecnologias

| Tecnologia | Uso no projeto |
| --- | --- |
| **Next.js — App Router** | Estrutura da aplicação, páginas e layouts |
| **React** | Construção da interface com componentes |
| **TypeScript** | Tipagem do código |
| **Tailwind CSS v4** | Estilização e personalização visual |
| **shadcn/ui** | Base de componentes, como cartões e botões, adaptados no próprio código |

A autenticação, a persistência de dados e a comunicação em tempo real fazem parte das próximas etapas. As tecnologias dessas integrações serão documentadas conforme forem adicionadas ao Orbit.

## 📍 Estado atual

O desenvolvimento está concentrado na tela de entrada e na composição visual do formulário.

- Estrutura inicial com Next.js, React e TypeScript.
- Estilização com Tailwind CSS.
- Construção do componente `SignInCard` com cartão, título, descrição e campos de e-mail e senha.
- Uso e personalização de componentes do shadcn/ui.
- Ajustes de tipografia, espaçamento e organização do código.

> Os campos e o botão da interface ainda não representam um fluxo de autenticação concluído. Login funcional, banco de dados e mensagens em tempo real não estão disponíveis nesta etapa.
